# MyFoodWorld 1.4.0 – iPhone

Versione web installabile gratuita, separata dall’app Android.

Apri https://acasciaro7-oss.github.io/Andrea/ in Safari, poi Condividi → Aggiungi alla schermata Home → Apri come app web.

Contiene 1.000 ricette e varianti, dosi, ricerca e filtri, frigo/freezer/dispensa, lista della spesa, scadenze a 3/7 giorni e diario nutrizionale. Logo e icone sono gli stessi approvati per Android.

La lettura delle foto avviene localmente con Tesseract.js nel browser: per scaricare il lettore e per cercare nuovi barcode serve Internet. Su iPhone non è presente il modello OCR nativo Android. Le funzioni principali funzionano offline dopo il primo caricamento completo.

L’indirizzo, l’identità dell’app e la chiave degli archivi rimangono invariati. Gli aggiornamenti non cancellano la dispensa. Ogni dispositivo mantiene dati separati: per trasferirli usa Impostazioni → Esporta/Importa backup. Prima di rimuovere l’icona installata o cancellare i dati di Safari esporta un backup.

L’aggiornamento del lettore o dell’app può richiedere la chiusura e riapertura della web app; quando compare un avviso premi Aggiorna dopo aver salvato i moduli aperti.

Nessun account, acquisto o API a pagamento richiesto. Non aggiungere dati personali al repository.
