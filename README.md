# La mia cucina - iPhone
Applicazione Web installabile dalla schermata Home di Safari, con visualizzazione a schermo intero, dispensa, ricette, lista della spesa e importazione tramite foto da verificare su iPhone.
**Uso gratuito, senza acquisti e senza account.** I dati di dispensa restano sul dispositivo (localStorage).
Non aggiungere dati personali a questo repository.
